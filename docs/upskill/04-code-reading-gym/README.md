# Code Reading Gym

This is where the learner stops passively reading and starts producing evidence.

Use the files in order:

1. `01-annotation-drills.md`
2. `02-trace-tables.md`
3. `03-fake-code-contrasts.md`
4. `04-review-katas.md`
